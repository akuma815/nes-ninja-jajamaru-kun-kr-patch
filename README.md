# 닌자 자자마루군 — 패미컴 / NES

패미컴 / NES **닌자 자자마루군** 한글 번역 패치 프로젝트입니다. 닌자 자자마루가 요괴와 싸우는 액션 게임입니다.

> **타이틀·메뉴 배포본 003**

## 다운로드 및 적용 방법

1. 아래 체크섬 또는 상세 안내와 일치하는 원본을 준비합니다.
2. [최종 배포 패치 다운로드](https://github.com/akuma815/nes-ninja-jajamaru-kun-kr-patch/releases/tag/title-menu-003)에서 ZIP을 받아 모두 압축 해제합니다.
3. IPS 패처에서 원본 NES ROM과 `Ninja_Jajamaru_kun_KR_title_menu_003.ips`를 지정합니다.
4. 원본을 보존하고 새 이름으로 저장한 ROM을 실행합니다.

## 주의사항

- 일본판 원본 전용입니다.
- 이번 범위는 타이틀 로고와 1인용·2인용 메뉴입니다.
- 원본 게임·BIOS 및 패치가 적용된 게임 이미지는 포함하지 않습니다.
