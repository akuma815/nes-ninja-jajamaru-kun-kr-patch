## 정리 상태

- 대상은 `Games/Ninja Jajamaru-kun` 폴더 하나다. 다른 게임·사이트·공개 릴리즈는 범위 밖이다.
- 사전 집계: 1,793파일·1,316,483,318바이트. 대상과 하위 경로의 재분석 지점은 0개다.
- 삭제 전에 재빌드 확인, 원격 Git 인계 반영, 별도 작업 기록 ZIP의 CRC·파일별 크기/SHA-256 검증을 완료한다.
- 작업 기록 ZIP에는 문서·소스·사양·자작 이미지·검증 캡처·보고서·배포 패치를 남긴다. 원본/완성 ROM·원본 그래픽 추출·원시 메모리·에뮬레이터·도구/의존성 바이너리는 제외하며 전체 폴더 복원용 백업으로 표현하지 않는다.
- 실제 삭제 결과와 백업 정보는 작업 완료 후 여기에 기록한다.

## 복원과 빌드

```powershell
git clone https://github.com/akuma815/nes-ninja-jajamaru-kun-kr-patch.git
Set-Location nes-ninja-jajamaru-kun-kr-patch
python -m pip install -r requirements.txt
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -SourceRom '별도로 준비한 지원 원본.nes' -TitleConfig config/release_v1_0.json
```

결과는 `build/title_kr_release_100/Ninja_Jajamaru_kun_KR_title_release_100.nes`, IPS는 `patches/Ninja_Jajamaru_kun_KR_title_release_100.ips`다. 위 원본 해시와 일치해야 한다. 폰트와 채택 자산은 Git에 있으므로 별도 추출물이나 외부 이미지 생성 작업 없이 최종 ROM·IPS를 재현한다. 배포 ZIP은 [v1.0 릴리즈](https://github.com/akuma815/nes-ninja-jajamaru-kun-kr-patch/releases/tag/v1.0)에서 받는다. 과거 런타임 원시 덤프는 공개 소스에 없으므로 예전 실행 증거 전체 재검사와 ZIP 패키징은 ROM·IPS 빌드와 구분한다.

## 검증 범위와 남은 사항

v1.0은 한글 타이틀·인원 메뉴·제주한라산체의 적 이름 7종·공통 등장 문구다. 타이틀 밖 영문은 유지한다. 기존 Mesen2.1.1 자연 부팅·첫 등장·시작·리셋·인원 선택 및 7종 제어 출력 검증은 공개 릴리즈 기록을 따른다. 이번에는 동일 바이트 재빌드와 배포 패치 대조를 수행했으며 새 플레이·전체 완주·실기 검증은 수행하지 않았다. 나머지 6종 자연 조우·숨은 문구 전체 분모·다른 에뮬레이터·오디오 청취도 미수행이다.
