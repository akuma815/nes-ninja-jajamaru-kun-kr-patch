## 변경 사항

`scripts/menu_assets.py`와 메뉴 사양을 추가했다. Galmuri7의 완성형 `인 / 용`을 원래 8px 크기, 공통 원점 (0,0), 8×8 셀로 렌더링한다. 숫자 1/2는 원본 타일을 유지한다. 기존 로고의 여유 타일 8A/8B에 두 글자를 배정하여 로고 86개 + 메뉴 2개 = 총 88/94 타일을 사용한다. 기존 영문 글리프는 변경하지 않는다.

`scripts/survey_menu.py`는 원본 메뉴 테이블과 소비 루틴을 조사한다. `analysis/menu_survey.json`, `menu_disassembly.json`에 원본 조사, `menu_final_disassembly.json`에 최종 ROM의 네 명령을 기록했다. CPU AC0E의 공유 테이블 읽기 및 AC11의 PPU 출력과 원본 런타임 trace를 대조했다. 원본 테이블은 파일 2C2A–2C30, 새 테이블은 `8A 8B 30 30 30 30 30`이고 소비 길이는 5다.

기존 명령의 즉시값 네 바이트만 변경했다. 파일 2BF8: 6D→6F, 2C0A: AD→AF, 2C17: 1C→30, 2C26: 07→05. 각각 메뉴 시작 열, 마지막 S 삭제, 루프 길이 조정이다. opcode·명령 길이·분기·실행 루틴 주소는 그대로다. 메뉴 경계는 (120,152,24,8), (120,168,24,8)이며 남는 영문 자리는 공백으로 지운다.

`build_title.py`는 로고와 메뉴의 전체 쓰기 계획을 확정한 뒤 원본 예상 바이트, 겹침, 허용 범위, 보호 바이트를 검사한다. `build.ps1`과 `config/title.json`은 현재 빌드로 연결한다. `capture_title.lua`는 메뉴 읽기 trace를 추가하고 `verify_title_qa.py`는 글자 위치·공백·소비 길이·이전 로고 유지까지 검사한다.

README, AGENTS, ARCHITECTURE, HANDOFF 진입 문서를 현재 범위로 갱신했다. 기존 날짜별 인계의 깨진 한글은 `docs/archive/HANDOFF_2026-10-10_before_menu003.md`에 보존하고 이 UTF-8 문서로 교체했다. 이전 002 작업의 상세 기록은 `docs/REVISION_title_kr_ai_002_2026-10-10.md`에 유지한다. 원본 및 001/002 빌드·패치·그림·QA 자료는 보존했다.

## 검증 구분

**정적 검사:** 지원 원본의 크기 32,784바이트·해시·헤더, CHR 1,024타일의 encode/decode 왕복, 94건 쓰기 계획, 변경 1,336바이트의 허용 범위와 보호 바이트, 최종 ROM에서 복원한 로고와 PNG의 일치, 작은 노란색 군의 높이 18px/본문 38px를 확인했다. 두 완성형 글자의 실제 cmap 항목은 `analysis/menu_font_coverage.json`에 기록했다.

**폰트 검사 제한:** `analysis/menu_font_audit.json`의 독립 종성 27종 검사는 FAIL이다. 27종이 동일 대체 글리프로 렌더링됐다. 이 폰트를 독립 종성 공급이나 조합형 폰트에 사용하지 않는다. 이번에는 실제 cmap과 픽셀을 확인한 완성형 두 글자만 사용했으며 전체 한글 지원을 주장하지 않는다. 실패 보고서와 preview를 그대로 보존했다. 폰트 및 공식 OFL 문서는 `assets/fonts/`에 있다.

**빌드·패치 적용:** 재빌드 ROM의 해시가 위 값과 동일하다. 원본에 생성 IPS를 실제 메모리 적용한 결과가 빌드 ROM과 바이트 단위로 일치한다. 이 검사는 Windows 배포용 apply.cmd 검증이 아니며 이번에 릴리스 패키지는 만들지 않았다.

**런타임 스모크:** Mesen 2.1.1에서 고유 ROM 이름과 격리된 portable 환경으로 콜드부트, 1인용 시작·초기 플레이 입력, reset 후 타이틀 복귀, Select로 2인용 선택·시작을 실행했다. 입력·캡처 시점·실행 파일·Lua 해시는 QA environment에 남겼다. 타이틀 bank/115개 로고 맵 읽기와 메뉴 공유 테이블 10회 읽기(2×5), 숫자·공백·PPU 위치가 최종 ROM과 일치한다. 실행 파일 원본 위치는 `../Tiny Toon Adventures/tools/mesen-2.1.1/Mesen.exe`이며 이 프로젝트의 QA 디렉터리에 복사해 실행했다.

**화면 비교:** 원본과 같은 시점의 12개 캡처에서 허용한 로고·메뉴 글자 영역 밖 변경 픽셀 0. 비타이틀 6개 화면은 전체 픽셀 동일. 12개 모두 OAM 동일. 이전 002와 비교하면 타이틀 6개는 메뉴 글자 영역의 402픽셀만 변경되고 비타이틀 6개는 동일하여 이전 로고가 유지됨을 확인했다.

**장면 시각 확인:** assistant가 실제 frame_0060, frame_0960, frame_0600 PNG를 직접 확인했다. 1인용/2인용 글자와 선택 커서, 작은 노란색 군, 메뉴 테두리, 초기 게임 화면을 확인했다. 사용자 미감 최종 확인은 아직 받지 않았다.

**미수행:** 전체 플레이, 실기, 다른 에뮬레이터, 오디오 청취, 전체 게임의 공유 타일 소비처 전수 조사. HUD·스테이지 안내·기타 게임 문구는 이번 변경 범위에 포함하지 않았다.

## 재현 명령

프로젝트 루트에서 실행한다. 주 빌드는 Python 3.12.10 / Pillow 12.3.0에서 확인했다.

```powershell
python -m pip install -r requirements.txt
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
python scripts/verify_title_qa.py
```

새 런타임 기록은 기존 QA를 덮어쓰지 않도록 새 출력 이름을 사용한다.

```powershell
python scripts/run_title_qa.py --rom build/title_kr_menu_003/Ninja_Jajamaru_kun_KR_title_menu_003.nes --output qa/title_kr_menu_003/cold_boot_002 --mesen '../Tiny Toon Adventures/tools/mesen-2.1.1/Mesen.exe'
python scripts/verify_title_qa.py --target-qa qa/title_kr_menu_003/cold_boot_002
```

조사 도구 py65는 선택 사항이다. 기존 로고 002 재현은 보존한 프로필을 명시한다.

```powershell
python -m pip install --target tools/python py65==1.2.0
python scripts/survey_menu.py
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1 -TitleConfig config/title_kr_ai_002.json
python scripts/verify_title_qa.py --config config/title_kr_ai_002.json
```
